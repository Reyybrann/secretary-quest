PANDUAN UPLOAD SEKRETARIS QUEST v1.5 FINAL

1. EKSPOR SAVE dari game lama jika perlu (Menu -> Ekspor Save).
2. Ekstrak file ZIP Github v1.5 FINAL.
3. Buka https://github.com/reyybrann/secretary-quest (branch yang dipakai GitHub Pages).
4. Add file -> Upload files, lalu tarik seluruh isi hasil ekstraksi
   (index.html, style.css, cek.html, src, vendor, assets, .nojekyll, dll.).
   HARUS mengganti index.html, style.css, src/main.js DAN src/office.js secara bersamaan.
5. Pastikan tidak ada folder pembungkus baru, index.html di root repositori.
6. Commit changes. Tunggu Settings -> Pages / Actions -> pages build and deployment sukses.
7. Cek https://reyybrann.github.io/secretary-quest/cek.html
   Semua status file harus HIJAU dan tulisan SIAP DIMAINKAN.
8. Buka https://reyybrann.github.io/secretary-quest/?versi=150
9. Pastikan tulisan v1.5 FINAL dan peta kantor tampak.
10. Di laptop emulasi HP: klik tahan dan geser analog.

Jika cek.html menunjukkan merah, publikasi belum lengkap: unggah ulang semua file.
