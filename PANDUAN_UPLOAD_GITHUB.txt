CARA UPDATE SECRETARY QUEST V1.4.0 (GITHUB PAGES)

1. Simpan save lama: jika diperlukan pilih Menu → Panduan & pengaturan → Ekspor Save.
2. Ekstrak Secretary_Quest_V1_4_FIX_HP_GITHUB.zip.
3. Buka github.com/reyybrann/secretary-quest.
4. Pilih Add file → Upload files.
5. Unggah SELURUH file dan folder HASIL EKSTRAK, bukan file ZIP atau folder pembungkusnya.
   Wajib berada di root: index.html, style.css, folder src, folder vendor, folder assets.
   Folder src wajib memuat touch-controls.js, screen-mode.js, main.js, office.js.
6. Klik Commit changes. Tunggu GitHub Pages selesai publish.
7. Buka https://reyybrann.github.io/secretary-quest/?v=140
8. Pastikan terlihat v1.4 kecil di bagian bawah. Buka tab Samaran bila masih terlihat versi lama.
9. Di HP: Lanjutkan/Main Baru → Ayo masuk kantor → geser analog.
10. Jika browser tak memutar landscape secara otomatis, game memutar layout 90 derajat: pilih Mengerti, kemudian putar HP fisik ke samping.

Untuk PC, kontrol WASD/panah/E tetap dan tidak perlu domain tambahan.
